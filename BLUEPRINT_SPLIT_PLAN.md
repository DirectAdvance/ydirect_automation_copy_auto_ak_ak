## Протокол на КАЖДЫЙ модуль
1. Чекпоинт-коммит перед.
2. Вырезать кластер → `NEW.py`, добавить `_deps={}` + функции.
3. blueprint: `from . import NEW as _new` + ре-экспорт + инъекция deps (`_new._deps.update({...})`), удалить перенесённое.
4. `python3 -m py_compile blueprint.py NEW.py` + `pyflakes` (0 undefined).
5. import-test на LXC (`from direct import blueprint`) + smoke http 302.
6. Прогон создания (детект тихих globals-разрывов) ИЛИ хотя бы delete-джоба (лёгкий импорт-контур воркера).
7. Коммит модуля. Следующий — только после зелёного.
