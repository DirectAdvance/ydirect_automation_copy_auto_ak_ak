## 3. Техника — витринный сплит, пак не трогаем

`site_type` — это **имя папки контент-пака** на M3 (`kontent_oktyabr/<site_type>/tpN/ctNNNN/`,
`kontent_pack._ct_dir` / `_remote_ct_dir`). Пак read-only, ночной `sync_content_m3.py` затрёт
самодеятельность. Литерал «Монобренд» захардкожен в 19 файлах (`SEGMENTS`,
`_AUTO_SEGMENT_SITE_TYPES`, `site_fit` ИИ-агентов, промо-гард, `AC_SITE_TYPES` в JS).

Поэтому:

- в `site_types[]` записи получают `name: "Монобренд · Lada"` + новое поле `pack_segment: "Монобренд"`;
- одна нормализация `kontent_pack.base_site_type(name)` в `_ct_dir` / `_remote_ct_dir`
  и в местах сравнения с литералами;
- пак, тексты, правила, `site_fit`, БУ-фильтры — **не трогаем**;
- **все 8 вкладок читают тот же сегмент пака «Монобренд»** — ни одна группа не теряет ключи.

## 4. Интерфейс `/direct/automation/slepki`

Вкладки рисуются из `site_types[].name` (`slepki_ui.js:863`) — появятся сами. Два уровня,
чтобы 8 вкладок не расползлись в строку:

```
[ Монобренд ] [ Мультибренд ] [ Мульти + БУ ] [ С пробегом ]
   └─ Все · Lada 84 · Tenet 69 · Общая 61 · Changan 27 · Haval 21 · Chery 10
```

Второй ряд — чипы марок с количеством групп **у выбранного слепка**; пустые не рисуются.
«Все» = нынешнее поведение.

## 5. Создание кампаний `/direct/automation?tab=create`

Сейчас тип сайта — жёсткий список `AC_SITE_TYPES` (`automation_create.js:1215`), 6 опций.
Предлагается строить его из структуры слепка + мультиселект марок при «Монобренде»:

```
Тип сайта:  ( Монобренд ▾ )
Марки:      [x] Lada  [x] Haval  [ ] Chery  [ ] Changan  [ ] Общая
            → в план уйдут N кампаний / M групп
```

Ничего не выбрано = все марки (поведение как сейчас, полный «Монобренд»).
