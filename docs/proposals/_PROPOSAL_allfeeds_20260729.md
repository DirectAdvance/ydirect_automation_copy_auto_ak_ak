## 5. Кодер новой группы «Все фиды» для каждой из 18

Формула: `ct0000_{aon|aoff}_n000_{r_code}_ct009_ag001_g00`.

- `aud`: во всех 18 именах кампаний присутствует «Автотаргетинг» → **aon** для всех 18 (в т.ч.
  для КС+-вариантов gordeeva/karavaev — там тоже есть суффикс «Автотаргетинг»).
- `r_code`: у ВСЕХ существующих items внутри всех 18 кампаний код в `gc` — **r0000** (проверено
  программно, других r-кодов не встречено ни в одной из 74 групп).

Итог: для **всех 18 кампаний** (и, соответственно, для всех 13 финальных) кодер новой группы
идентичен:

```
ct0000_aon_n000_r0000_ct009_ag001_g00
```

Это подтверждает тривиальность слияния items при схлопывании Оп.3 — у сливаемых пар совпадают
и `t` («Все фиды»), и `gc` полностью, различаются только исходные `camp_names`, которые после
Оп.2-переименования становятся идентичной строкой.
