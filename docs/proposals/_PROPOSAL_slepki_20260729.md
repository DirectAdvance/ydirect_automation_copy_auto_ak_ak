# Аудитории (задача 1)

## Что сделано

Создана кампания tp1 **«AUDIT - tp1 - аудитории слепков»** (id `713125681`) на `porg-azsw6eyh`,
черновик, State=OFF. В неё через `audiencetargets.add` заводились аудитории из ВСЕХ слепков
поштучно — так Директ отдаёт код ошибки на каждую отдельно.

## Главное: «не добавляется» ≠ то, что казалось

Первые прогоны врали — Директ рубил ЦЕЛЫЙ пакет из-за лимитов, а не конкретную аудиторию:

- не более **50** условий подбора на группу;
- условие типа «Интересы и привычки» — **только одно** на группу.

Поштучно на свежих группах прикрепилось **всё**, включая ЛАЛ и ретаргетинг.
Но: `retargetinglists.get` по этим id возвращает **пусто** — кабинет их не содержит.
То есть API принимает чужой id, а привязка получается фантомной. Поэтому критерий
«API принял» негодный, и я мерил тем же, чем меряет сам сервис
(`create_set_audiences.resolve_for_account`): резолв по id донора, иначе по имени.
